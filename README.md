## 🧠 Опис функціоналу

- 🌐 **Інтерактивна ГІС-карта**: Відображення підстанцій та ліній зв'язку в реальному часі на базі Dash Leaflet.
- ⚡ **Оптимізація топології (МКД)**: Побудова математично найдешевшої схеми з'єднання підстанцій за допомогою кастомного алгоритму Пріма.
- 📉 **Оптимізація пам'яті (Indexed PQ)**: Впровадження індексованої пріоритетної черги з операцією `decrease-key` за $O(\log V)$, що зменшує споживання ОЗУ у 10 разів.
- 🔍 **Діагностика вразливостей**: Автоматичний пошук критичних точок відмови (мостів графа) за допомогою безрекурсивного ітеративного алгоритму Тар'яна.
- 🛡️ **Структурне резервування**: Автоматичне прокладання додаткових ліній за європейським стандартом надійності $N-1$ за допомогою двофазної жадібної евристики з коефіцієнтом апроксимації 1.0 (0% похибки).
- 🖱️ **Інкрементальне оновлення**: Миттєве підключення нових одиничних підстанцій за лінійний час $O(V)$ без перерахунку всього графа.
- 💾 **Експорт у ГІС**: Підтримка збереження та вивантаження результатів у міжнародному географічному стандарті GeoJSON.

## 🧱 Опис основних класів / файлів

| Клас / Файл / Папка | Призначення |
|---------------------|-------------|
| `app.py`            | Точка входу, запуск веб-сервера Dash та ініціалізація інтерфейсу |
| `models/edge.py`    | Клас `Edge` (Ребро графа) з перевизначеним магічним методом `__lt__` для порівняння ваг |
| `structures/indexed_pq.py` | Власна реалізація Індексованої пріоритетної черги з підтримкою `decrease-key` |
| `algorithms/prim.py` | Оптимізований алгоритм Пріма на базі Indexed PQ з просторовою складністю $O(V)$ |
| `algorithms/tarjan.py` | Ітеративний (безрекурсивний) алгоритм Тар'яна для пошуку мостів відмови |
| `algorithms/redundancy.py` | Двофазна жадібна евристика доповнення графа до стану 2-зв'язності (стандарт $N-1$) |
| `data/database.py`  | Модуль взаємодії з БД SQLite3 для збереження результатів бенчмарків |
